Keycap math

The group buy ends in six hours, the set has 140 keys, and your 65% board needs a short right shift the render gallery never shows. Keycap math counts the set against your layout - base keys and the odd sizes - prices the keys you will actually use against the ones that ride along unused, and checks whether one set can dress two boards at once. Exact counting, every layout assumption labeled.

Open the calculators

The three tools

  • Coverage plan - set keys and specials against your board's keys and specials.
  • Price plan - price per key in the box versus per key your board uses.
  • Layout plan - leftover keys after the first board, and whether the second gets dressed.

Labeled norms

Labeled board: 68 keys (a 65%). Labeled set: 140 keys with 2 special sizes. Labeled price: $120. These are reference values, not recommendations - key counts ignore profile and row sculpt, so check the set's kitting diagram against your layout before any buy.
